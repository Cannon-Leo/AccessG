# AccessG: Business Brief

**The Business**
AccessG is a dual-engine event ticketing platform. It provides fast-checkout general admission for mid-sized public events, alongside "AccessG Studio"—a high-trust portal for creators hosting micro-events (under 20 attendees) requiring specialized data collection like dietary needs and portfolio links. 

**The User**
Users are digital-native young professionals (18–35) accessing the platform primarily via mobile devices. While they expect fast, minimalist interfaces and seamless digital wallet integrations, they frequently operate in hostile network environments—relying on congested 4G networks while standing in dense crowds outside venues.

**The One Thing That Must Work**
Ticket retrieval and gate scanning. A user must be able to instantly retrieve their digital pass and QR code upon arrival. If the ticket fails to load due to a frontend crash or poor network handling, the user is stranded outside, the gate bottlenecks, and the business loses its core utility.

**Three Repeated Questions**
1. Did my payment clear and secure my limited-capacity seat?
2. Where is my digital ticket and QR code for gate scanning?
3. Is the waitlist open for this sold-out creator event?

**The Interface and Aesthetic**
The platform demands a high-contrast, dark-mode visual architecture. Because users interact with the app in low-light environments (nightlife venues, studio spaces), the interface requires a stark, utilitarian typography system ensuring gate staff can read names and ticket tiers instantly. Animations should be restrained and velocity-driven, prioritizing perceived performance and strict component modularity over decorative flair.
